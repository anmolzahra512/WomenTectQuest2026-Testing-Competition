### Challenge 3: AI Chatbot Quality Evaluation

Target: the "Ask ElectraStore" assistant on validate.womentechquest.com (ElectraStore is a fictional appliance retailer).

Scope covered:
- Consistency
- Hallucinations
- Prompt sensitivity
- Context handling
- Accuracy
- Safety and reliability

Report sections: observations, risks, recommendations, final quality assessment.

Submission questions:
1. QA strategy and methodology used
2. Tools and techniques selected and why
3. How responses were critically validated

### Challenge 2: AI-Assisted Application Evaluation

Re-test the Challenge 1 application using AI assistance, then compare the AI-assisted findings against the manual bugs found earlier.
